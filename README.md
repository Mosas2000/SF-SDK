# SFSec SDK

**Security-focused SDK for SprintFund platform on Stacks blockchain**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 🚧 Status: In Development

This repository contains modular packages for building secure decentralized governance applications on the Stacks blockchain.

## 📦 Packages

- **[@sfsec/core](./packages/core)** - Core SDK functionality (client, types, utilities)
- **[@sfsec/security](./packages/security)** - Security utilities (validation, sanitization)
- **[@sfsec/contracts](./packages/contracts)** - Smart contract interactions
- **[@sfsec/metrics](./packages/metrics)** - NPM download metrics and analytics

## 🎯 Features

- ✅ Security-first architecture
- ✅ TypeScript support with full type definitions
- ✅ Comprehensive input validation and sanitization
- ✅ Smart contract interaction utilities
- ✅ Transaction polling and status tracking
- ✅ Error handling framework
- ✅ Caching and retry mechanisms

## 🔒 Security

Security is our top priority. This SDK includes:

- Comprehensive input validation
- XSS prevention through sanitization
- Content Security Policy (CSP) helpers
- Regular security audits
- Responsible disclosure process

See [SECURITY.md](./SECURITY.md) for our security policy.
